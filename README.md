# UBTlogia — исправления версии 11

Скачайте UBTlogia-Fixes-v11.zip и распакуйте. В папке ubtlogia запустите
DEPLOY_NETLIFY.bat с установленным Node.js 22 или новее.
При привязке выберите существующий проект Netlify ubtlogia.

Исправлены переключение физики/информатики и встроенный плеер. Поддержаны
YouTube, Rutube и Vimeo. Проверено 15 тестов и 20 браузерных сценариев.

Полный подбор видео пока НЕ завершён: тематические привязки есть у 17 из
118 тем, у 101 темы видео пока нет. Реальное воспроизведение новых площадок
не подтверждено. Ограничения и подробный отчёт — в AUDIT.md внутри архива.

Этот архив не публикует сайт автоматически.
Старые противоречивые настройки версии 10 исправляются автоматически.

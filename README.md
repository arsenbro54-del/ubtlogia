# UBTlogia — обновление сайта

Скачайте UBTlogia-Windows.zip, распакуйте его и откройте папку ubtlogia.
Для установки обновления нужен Node.js 22 или новее. Запустите DEPLOY_NETLIFY.bat
и выберите существующий проект Netlify ubtlogia.

В архиве: 42 урока физики на русском и казахском, 235 задач, справочник формул,
оба PDF и исправления сайта. Подробности и ограничения — в AUDIT.md внутри архива.
Новый подбор проверенных видео ещё не завершён. Сам сайт пока не опубликован.

Эта ветка содержит архив для скачивания.
